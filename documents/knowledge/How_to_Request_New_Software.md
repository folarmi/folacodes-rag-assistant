# How to Request New Software

## When Should You Request Software?

Submit a request when software is required to perform your job.

---

## Information Required

Include:

- Software name
- Business purpose
- Vendor
- Estimated cost
- Number of users
- Required installation date

---

## Review Process

1. Employee submits request.
2. Line Manager approves.
3. IT reviews security.
4. Finance reviews cost (if applicable).
5. Software is installed.

---

## Typical Timeline

Most requests are completed within **5 business days**.

---

## Important

Employees must not install unapproved software.
