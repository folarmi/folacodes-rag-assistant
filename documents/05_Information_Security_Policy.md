# Information Security Policy

## 1. Purpose

Folacodes Technologies is committed to protecting its information assets, customer data, employee information, intellectual property, and technology infrastructure from unauthorized access, disclosure, alteration, loss, and destruction.

This policy establishes the minimum security requirements all personnel must follow.

This policy supports compliance with applicable privacy laws, contractual obligations, and industry best practices.

Related Policies:

- POL-001 Employee Handbook
- POL-002 Code of Conduct
- POL-003 Remote Work Policy
- POL-006 IT Acceptable Use Policy
- POL-009 Data Privacy Policy

---

# 2. Scope

This policy applies to:

- Employees
- Contractors
- Consultants
- Interns
- Temporary Staff
- Third-party vendors granted access to company systems

Every person with access to company information must comply with this policy.

---

# 3. Security Objectives

The company's information security program is built around protecting:

- Confidentiality
- Integrity
- Availability

Every security control implemented by Folacodes Technologies supports one or more of these objectives.

---

# 4. Information Classification

Information must be classified according to its sensitivity.

| Classification | Description                     | Example                                                         |
| -------------- | ------------------------------- | --------------------------------------------------------------- |
| Public         | May be shared publicly          | Marketing brochures                                             |
| Internal       | Intended for employees only     | Internal procedures                                             |
| Confidential   | Restricted business information | Financial reports                                               |
| Restricted     | Highly sensitive information    | Customer personal data, encryption keys, production credentials |

Employees must handle information according to its classification.

Restricted information must never be shared outside approved systems.

---

# 5. Password Requirements

Passwords must:

- Contain at least **14 characters**
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Be unique for every company account

Employees must not:

- Reuse company passwords elsewhere
- Share passwords
- Write passwords on paper
- Store passwords in unencrypted documents

The use of an approved password manager is strongly encouraged.

---

# 6. Multi-Factor Authentication (MFA)

Multi-Factor Authentication is mandatory for all company accounts.

MFA must be enabled for:

- Email
- VPN
- Cloud applications
- Development platforms
- Source code repositories
- Administrative systems

Employees may not disable MFA.

---

# 7. Device Security

Only approved devices may access company resources.

Company-issued devices must:

- Use full disk encryption
- Run approved antivirus software
- Receive automatic operating system updates
- Lock automatically after 10 minutes of inactivity
- Be protected with strong passwords or biometrics

Lost or stolen devices must be reported within **24 hours**.

---

# 8. Bring Your Own Device (BYOD)

Personal devices may only access company resources when approved by the IT Department.

Approved devices must:

- Have screen lock enabled
- Support remote wipe
- Run current operating system versions
- Use antivirus software where applicable

Restricted company data may not be permanently stored on personal devices.

---

# 9. Remote Access

Employees working remotely must:

- Connect through the company VPN
- Use secure internet connections
- Avoid public computers
- Lock devices when unattended

Public Wi-Fi should only be used together with the company VPN.

---

# 10. Email Security

Employees must exercise caution when handling email.

Employees must:

- Verify unexpected requests.
- Confirm payment instructions through an alternative communication channel.
- Avoid opening suspicious attachments.
- Report phishing attempts immediately.

Sensitive information should never be sent through unsecured email.

---

# 11. Artificial Intelligence (AI) Usage

Approved AI tools may be used to improve productivity.

Employees must not submit the following into public AI systems without written approval:

- Customer data
- Employee records
- Source code
- Financial information
- API keys
- Passwords
- Confidential business strategies
- Legal documents

Where approved enterprise AI platforms exist, employees should use those platforms instead of public services.

---

# 12. Data Storage

Company information must be stored only in approved systems.

Examples include:

- Microsoft SharePoint
- Microsoft OneDrive (Corporate)
- Company-managed cloud storage
- Approved databases

Employees may not store confidential business information in personal cloud storage accounts.

---

# 13. Software Installation

Employees may only install software approved by the IT Department.

Unauthorized software includes:

- Pirated software
- Cracked applications
- Unlicensed utilities
- Cryptocurrency mining software

Requests for new software should be submitted through the IT Service Desk.

---

# 14. Security Incident Reporting

Employees must immediately report:

- Lost devices
- Malware infections
- Phishing emails
- Unauthorized access
- Data breaches
- Suspicious account activity
- Accidental disclosure of confidential information

Reports should be made within **one hour** of discovery whenever reasonably possible.

Reports may be submitted through:

- IT Service Desk
- Information Security Team
- Emergency Security Hotline

Prompt reporting helps reduce business impact.

---

# 15. Incident Severity Levels

| Severity | Description                | Example               |
| -------- | -------------------------- | --------------------- |
| Critical | Major business impact      | Customer data breach  |
| High     | Significant security event | Ransomware infection  |
| Medium   | Limited business impact    | Malware on one laptop |
| Low      | Minor security issue       | Spam email            |

The Information Security Team determines the final incident severity.

---

# 16. Physical Security

Employees must:

- Wear identification badges in company offices.
- Challenge unknown visitors politely.
- Escort visitors where required.
- Lock confidential documents away.
- Secure laptops before leaving workstations.

Visitors must sign in at reception.

---

# 17. Security Awareness Training

All employees must complete mandatory information security awareness training:

- Upon joining the company.
- Annually thereafter.
- Following significant policy updates where required.

Employees may also participate in periodic phishing simulations.

Failure to complete mandatory training may result in suspension of access to company systems.

---

# 18. Third-Party Access

Third parties requiring access to company systems must:

- Obtain business approval.
- Sign appropriate confidentiality agreements.
- Receive only the minimum access necessary.
- Use Multi-Factor Authentication.

Access is reviewed at least every six months.

---

# 19. Policy Exceptions

Requests for exceptions to this policy must:

- Be documented.
- Include business justification.
- Identify associated risks.
- Be approved by the Information Security Manager.

Exceptions are temporary and subject to periodic review.

---

# 20. Responsibilities

## Employees

Employees are responsible for:

- Protecting company information.
- Reporting incidents immediately.
- Following security procedures.
- Completing mandatory training.

---

## Managers

Managers are responsible for:

- Reinforcing secure behaviour.
- Ensuring employees complete training.
- Reporting security concerns.

---

## Information Security Team

The Information Security Team is responsible for:

- Monitoring threats.
- Investigating incidents.
- Maintaining security controls.
- Updating this policy.
- Conducting security awareness programmes.

---

# 21. Frequently Asked Questions

### Can I save company files in my personal Google Drive?

No. Company information must only be stored in approved corporate systems.

---

### Can I use ChatGPT for work?

Yes, but confidential information, source code, customer information, passwords, financial information, API keys, and other restricted information must never be entered into public AI tools without written approval.

---

### What should I do if I click a phishing email?

Disconnect from the network if instructed by IT, report the incident immediately to the Information Security Team or IT Service Desk, and do not attempt to investigate the issue yourself.

---

### How quickly should I report a suspected security incident?

Employees should report security incidents within **one hour** of discovery whenever reasonably possible.

---

### Can I disable MFA temporarily?

No. MFA is mandatory for all company accounts.

---

Questions regarding this policy should be directed to the Information Security Team.
