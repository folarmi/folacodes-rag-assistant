# AI Tooling Report

## AI Tools Used

The following AI tools were used during development:

- ChatGPT
- GitHub Copilot
- Groq Playground

---

# How AI Was Used

AI tools were used for:

- Debugging Python code
- Explaining errors
- Generating boilerplate code
- Refactoring functions
- Writing unit tests
- Creating Docker configurations
- Explaining RAG concepts
- Improving documentation

---

# What Worked Well

- Faster debugging
- Faster code generation
- Better understanding of unfamiliar libraries
- Assistance with Docker and deployment
- Improved productivity

---

# Limitations

- Generated code occasionally contained syntax errors.
- Suggested solutions sometimes required manual correction.
- Deployment advice occasionally needed adaptation for the Render free tier.
- AI-generated code still required testing and validation.

---

# Conclusion

AI tools accelerated development and improved productivity, but human review and testing remained necessary to ensure correctness and reliability.
